### Odin and Win32 API Examples Repository

This repository contains examples on how to use Odin and the Win32 API. This repository was created as a way to
save things I am/was learning while working through Win32 and Odin.

These examples are not guarenteed to be the best usage examples of them, but they do show how to do things

This repository does get updated from time to time as I mess around with the Win32 API more and learn more things. Though it's not updated
frequently. There may be times this repository gets updated a lot in small bursts, and nothing for months on end.

This repository originally stared out as a place to store GDI examples, but has since grown into the Win32 API Examples as a whole, so there is a lot
of GDI examples compared to others as a result.


## How to run

Every example (unless specified otherwise) can be run using: `odin run .`

## How these examples where created

These examples where created using/referencing:
  - Win32 Documentation: https://learn.microsoft.com/en-us/windows/win32/
  - Odin Language Windws Package Code: core/sys/windows
  - Odin Language Overview Page: https://odin-lang.org/docs/overview/
  - AI Tools (Phind, Copilot, Local AI Models): Asking questions, clarification, C based examples for reference
